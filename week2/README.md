# Week 2 Python Scripts
This repository contains the fundamental concepts of writing Python code.

## Description

This repository contains Python scripts developed during Week 2 of the bioological computing bootcamp. The files cover the 
basic concepts in Python such as input/ ouput operations, control flow, loops, lists, dictionaries, tuples, module usage
and debugging Python code. These exercises can be found on the MulQuaBio under "Biological Computing in Python". Some of these scripts
contain full python modules which can be run independently. Further, some read from "../data", and write output to "../results".


### Requirements
Python 3.x
No additional packages required
