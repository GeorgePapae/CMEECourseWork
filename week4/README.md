# Python: Performance & Population Models
## Description

This repository contains Python scripts developed during Week 4 of the bioological computing bootcamp. The files contain:
- Mathematical modelling with the Lotka-VOlterra consumer-resource model
- Performance profiling

## Overview
- **code/** - Contains the code worked on
- **data/** - COntains data files 
- **results/** - Contains output files generated by the scripts

## Code Contents
- 'LV_model.py' - Lotka-Volterra model of consumer-resource population dynamics
- 'profileme.py' - COntains functions for profiling
- 'profileme2.py' - Contains functions for profiling
- 'timeitme.py' - Compares performance of different coding approaches

## How to run
Most scripts can be executed from the bash terminal using:

```bash
python3 script_name.py
```
