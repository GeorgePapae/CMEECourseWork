# Introduction to R
## Description

This repository contains R scripts developed during Week 3 of the bioological computing bootcamp. The files contain:
- Data wrangling 
- Mathematical modeling
- Plotting and visualisation
- Vectorisation, loops and control flow

## Repository Structure
- **code/** - Contains the code worked on
- **data/** - Contains data files 
- **results/** - Contains output files generated by the scripts

## Code Contents
- DataWrang.R - Data wrangling of the Pound Hill Dataset
- DataWrangTidy.R - Data wrangling of the Pound Hill Dataset using tidyverse
- Florida.R - Permutation test on Key West Annual Mean Temperature data
- Florida.tex - LaTeX file for the permutation test of 'Florida.R'
- Girko.R - Plotting the eigenvalues of a random matrix to illustrate Girko's circle law
- MyBars.R - Creating a linerange plot using ggplot2 in R
- PP_Dists.R - Analyzing predator-prey body mass distributions
- PP_Regress.R - Performing regression analysis on predator-prey body mass data
- R_conditionals.R - Examples of conditional statements in R
- Ricker.R - Implementation of the Ricker model in R
- SQLinR.R - Using SQL databases within R
- TreeHeights.R - Calculating tree heights from distance and angle data
- Vectorize1.R - Comparing loop-based and vectorized summation in R
- Vectorize2.R - Vectorized implementation of the stochastic Ricker equation in R
- apply1.R - Demonstration of the apply function in R
- apply2.R - Using apply with a custom function in R
- basic_io.R - A simple script to illustrate R input-output
- boilerplate.R - A boilerplate R script
- break.R - Demonstration of the break statement in R
- browse.R - Demonstration of the browser function in R
- control_flow.R - Demonstration of control flow in R
- next.R - Demonstration of the next statement in R
- plotLin.R - Plotting a linear regression with ggplot2 in R
- preallocate.R - Demonstration of preallocating vectors in R for efficiency
- sample.R - Sampling experiments with different implementations in R
- try.R - Demonstration of error handling in R using try and stop

## How to run
Most scripts can be executed from the bash terminal using:

```bash
Rscript script_name.R
```
