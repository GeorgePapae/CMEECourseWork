# Biological Computational Bootcamp

## Description

This repository contains all work carried out for the Biological Computational Bootcamp. It consists of 4 weeks, with each week focusing on different foundational computational skills

## Repository Structure
The repository is organised into weekly folders:
**week1/** 
**week2/** 
**week3/** 
**week4/** 
Each week contains:
- **code/** - Contains the code written this week
- **data/** - Input data files
- **results/** - Generated outputs

## Weekly Summaries

- **Week 1** - UNIX, Shell Scripting, and LaTeX
- **Week 2** - Introduction to Python
- **Week 3** - Introduction to R
- **Week 4** - Python: Performance & Population Models

See weekly README.md files for more details, including how to run the scripts
